# Formação de Preço de Venda

Calculadora que forma o preço de venda a partir das ofertas de compra, do estado, do regime tributário (ICMS, PIS/COFINS, Simples) e das fases da reforma tributária (CBS e IBS).

Página única (`index.html`), sem dependências de build. Publicada pelo GitHub Pages a partir da branch `main`, pasta raiz.

Simulação gerencial: confirme alíquotas e créditos com a contabilidade antes de fechar preços.
